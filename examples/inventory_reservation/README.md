# Inventory Reservation Demo

这是一个故意保留 Bug 的小型库存项目，用于演示编程智能体完成真实修复任务。

业务规则：一次订单可以预留多种商品。只有全部商品库存都足够时才能扣减；如果任意商品不足，整个操作必须失败，并保持所有库存不变。

初始测试中有一项会失败：程序可能先扣掉前面的商品，随后才发现后面的商品库存不足。

运行测试：

```powershell
python -m unittest discover -s tests -v
```

推荐给智能体的任务：

```text
请修复当前项目中的失败测试。业务要求：一次订单包含多个商品；如果任何一个商品库存不足，这次预留必须整体失败，任何商品的库存都不能变化。不要修改测试，也不要降低断言。请先检查项目并运行测试定位问题，只做必要修改，最后再次运行测试确认全部通过。
```

完成一次演示后，可在仓库根目录恢复最初的 Bug，方便重新练习：

```powershell
python examples\reset_inventory_demo.py
```
