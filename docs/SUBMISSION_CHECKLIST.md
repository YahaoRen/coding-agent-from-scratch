# 提交前检查表

截止时间：2026 年 9 月 2 日 24:00（北京时间）。截止后不要再向仓库推送提交。

## Git 仓库

- [ ] 仓库公开，可以在退出登录后打开。
- [ ] 仓库是题目发布后新建的，完整提交历史仍保留。
- [ ] 默认分支代码能正常运行，全部项目测试通过。
- [ ] 仓库、历史和文档中没有 API Key、访问令牌或其他真实凭据。
- [ ] README 中没有姓名、本科院校等身份说明。

## README.txt

- [ ] 文件名严格为 `README.txt`。
- [ ] 不超过 1000 汉字。
- [ ] 包含公开仓库地址、运行方法和特色功能。
- [ ] 不包含 API Key 或身份介绍。

## 视频

- [ ] 展示一个真实编程任务从失败到修复成功的过程。
- [ ] 简单讲到核心循环、工具和至少一项安全设计。
- [ ] 不超过 2 分钟，MP4 格式，不超过 200 MB。
- [ ] 画面和声音中没有姓名、学校、个人账号、完整用户目录、通知或 API Key。
- [ ] 从头播放检查过声音、画面、字幕和加速片段。

## 最终 ZIP

- [ ] ZIP 内只包含 `README.txt` 和视频文件，不包含源码仓库或 `.env`。
- [ ] ZIP 文件按题目要求用本人姓名命名；ZIP 内部材料仍保持双盲。
- [ ] 解压测试成功，两个文件都能正常打开。
- [ ] 文件已通过通知中的表单提交；若重复提交，确认最后一次是正确版本。

## 面试准备

- [ ] 45–55 秒英文介绍已经计时练习。
- [ ] 能用自己的话解释“模型 → 工具 → 结果 → 模型”的循环。
- [ ] 能说明为什么要限制路径、审批命令、裁剪上下文和停止重复调用。
- [ ] 能诚实说明项目没有操作系统级沙箱等已知不足。
