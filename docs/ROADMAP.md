# 开发路线

项目按可运行的功能里程碑逐步实现。核心开发阶段已经完成；剩余工作是接入最终模型、验证演示稳定性并录制视频。

1. 建立项目骨架、命令行入口和密钥保护规则。
2. 实现配置读取与 OpenAI 兼容模型客户端。
3. 实现消息结构、工具协议和 Agent 主循环。
4. 实现文件读取、目录浏览和文本搜索工具。
5. 实现文件写入、精确编辑和本地命令执行。
6. 增加路径边界、超时、输出截断、最大轮数和错误恢复。
7. 增加上下文控制、会话记录、完整测试和演示任务。
8. 增加本地浏览器任务台、执行时间线、逐项审批和安全停止。

## 已完成的额外加固

- 敏感文件和内部元数据统一拒绝访问。
- 已知密钥在模型消息、工具结果和会话记录中统一脱敏。
- 被截断的模型回答不会误报为完成。
- 连续重复工具调用会提前停止。
- 单轮工具结果有总大小预算。
- `--yes` 与高风险的 `--yes-all` 分开，普通自动模式仍会询问命令。
- CLI 和网页共用同一运行时，避免安全规则出现两套实现。
- 网页只监听本机地址，并校验页面令牌、Host 和 Origin。
- 停止信号会进入 Agent 循环和正在运行的命令，关闭工作台会等待后台安全收尾。

## 提交前剩余工作

1. 配置最终选用的真实模型接口。
2. 在全新演示副本上连续完成至少三次修复任务。
3. 根据真实模型在任务台中的输出微调视频节奏和讲解词。
4. 完成匿名视频并按检查表核对最终 ZIP。
