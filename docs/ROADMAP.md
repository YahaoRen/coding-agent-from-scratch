# 开发路线

项目按可运行的功能里程碑逐步实现。每一步先测试，再单独提交并推送。

1. 建立项目骨架、命令行入口和密钥保护规则。
2. 实现配置读取与 OpenAI 兼容模型客户端。
3. 实现消息结构、工具协议和 Agent 主循环。
4. 实现文件读取、目录浏览和文本搜索工具。
5. 实现文件写入、精确编辑和本地命令执行。
6. 增加路径边界、超时、输出截断、最大轮数和错误恢复。
7. 增加上下文控制、会话记录、完整测试和演示任务。

## 参考方式

开发会研究以下项目的设计取舍，但代码从空仓库独立实现：

- `shareAI-lab/learn-claude-code`：循序渐进的教学结构。
- `SWE-agent/mini-swe-agent`：精简的 Agent 循环与本地执行思路。
- `rasbt/mini-coding-agent`：权限、上下文和会话设计。

本项目不复制这些仓库的源码，也不依赖任何现成 Agent 框架或 Agent SDK。
