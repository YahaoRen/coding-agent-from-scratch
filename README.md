# Coding Agent from Scratch

一个从零实现的轻量编程智能体。项目强调代码清晰、依赖少，并完整展示模型交互、工具执行、上下文管理和终止判断，而不是封装现有 Agent 产品或框架。

## 当前进度

当前已提供可运行的命令行入口、环境配置读取、不依赖第三方包的 OpenAI 兼容模型客户端、自建工具注册层、有明确终止条件的 Agent 主循环，以及受限的文件浏览、编辑和命令执行工具。后续功能会以小步、可验证的提交逐步加入。

## 设计原则

- 只使用 Python 标准库和普通模型 API 客户端，不使用 Agent 框架或 Agent SDK。
- 每个模块只负责一类功能，优先选择容易阅读和解释的实现。
- 每个功能里程碑都附带测试，已推送的 Git 历史不改写。
- API Key 只从环境变量或未跟踪的本地配置读取。
- 工具错误会转换成结构化结果交还模型，不因一次失败终止整个进程。
- 主循环限制模型轮数与工具调用总数，避免模型陷入无限执行。
- 所有模型提供的文件路径都先经过统一工作区边界检查。
- 文件列表、文件读取和文本搜索都限制返回规模并跳过二进制内容。
- 写入和执行属于副作用操作，默认拒绝；写文件采用原子替换，精确编辑拒绝模糊匹配。
- 命令以参数数组、`shell=False`、固定工作目录运行，并限制时间和输出规模。
- 上下文按完整工具交互分组裁剪，始终保留系统指令、原始任务和最近结果。
- 连接失败、限流和服务端错误使用有上限的指数退避重试；鉴权及协议错误不重试。

命令审批只是本机模式的安全护栏，并不是操作系统级沙箱。即使固定了工作目录，获批命令仍可能访问工作区外的资源；因此只应对可信项目使用自动批准模式。

## 运行

要求 Python 3.10 或更高版本。

```powershell
python -m coding_agent --help
python -m coding_agent --version
python -m coding_agent doctor
python -m coding_agent run "修复当前项目中的失败测试" --workspace .
```

运行测试：

```powershell
python -m unittest discover -s tests -v
```

## 模型配置

复制 `.env.example` 为 `.env`，填写以下本地配置：

```text
CODING_AGENT_API_KEY=你的密钥
CODING_AGENT_BASE_URL=兼容接口的 /v1 地址
CODING_AGENT_MODEL=模型名称
```

`.env` 已被 Git 忽略，真实密钥不得写进其他代码、文档或提交历史。模型适配器使用普通的 `/chat/completions` 接口；工具定义和 Agent 循环均由本项目自行实现。

默认情况下，只读工具自动运行，写入和命令逐次询问。仅在隔离或完全可信的工作区中使用 `--yes` 自动批准。
